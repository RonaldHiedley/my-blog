# TaskForge

O TaskForge é um projeto pessoal de gerenciamento de tarefas.

A ideia é construir um sistema relativamente simples, mas que permita explorar conceitos importantes de desenvolvimento de software.

## Objetivos

- Praticar Java e Spring Boot
- Trabalhar com APIs REST
- Utilizar PostgreSQL
- Explorar autenticação e autorização
- Trabalhar com containers
- Aplicar conceitos de arquitetura de software

## Tecnologias

- Java
- Spring Boot
- PostgreSQL
- Docker

## Status

Em desenvolvimento.

O projeto será evoluído conforme novos conceitos forem sendo estudados e implementados.
